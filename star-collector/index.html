When should
the score change?

Arrow keys move the robot. A condition checks how close it is to the star. When the distance is less than 30, the score increases by one and the robot returns to its starting point.

Play, then change a rule

Download the Scratch project ↓

.sb3 file · about 3 KB · no Codewarts account or email needed

  1. Open the Scratch editor ↗ on a laptop or desktop.
  2. Choose File → Load from your computer, then select the downloaded .sb3 file.
  3. Press the green flag. Use the left and right arrow keys to move.
  4. Select the Robot sprite to inspect its blocks.

You can also open the file in the Scratch desktop app if you already use it. The video is an edited project demonstration with scripted controls, reused Hannah AI narration and a custom renderer of real Scratch VM states. It is not a student result or a screen recording of a lesson.

One small experiment

Find the condition below in the Robot's blocks. Predict what will happen if you change 30 to 60. Then press the green flag and test it again.

if distance to [Star] < 30
    change [Score] by 1
    go to x: -180 y: -50

Predict: Will the score change closer to the star, or farther away?

Test: What changed when you tried 60?

Explain: What stayed the same about the robot's movement?

Check the idea after testing

A larger distance threshold lets the condition become true farther from the star. The movement blocks still change x by 5. Only the condition's number changed. A score increase here means “near enough” according to the program; it does not require the robot artwork to overlap the star.
