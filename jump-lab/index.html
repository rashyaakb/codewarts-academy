A tiny coding experiment

Can one number
change the jump?

Help the character reach the coin. Choose a jump speed, predict what will happen, then test it.

This is a simplified, playable version of our original Python demonstration. It illustrates a coding idea; it is not a student result or a promised trial project.

jump_speed = -10
self.vy = jump_speed
self.vy += GRAVITY
self.y += self.vy

Here, a more negative starting speed moves the character upward faster. Gravity stays the same.

Why does changing the number work?

On screen, y increases downward. A negative vertical speed moves the character upward. Gravity adds 0.7 each step, gradually slowing the climb and pulling the character back down. We hold the coin, horizontal speed and gravity fixed so you can compare just the jump speed.
